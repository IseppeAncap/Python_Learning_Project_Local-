# 🧠 Revisando o codigo de introdução lambda parte.

 1. O codigo começa com uma lista ( matriz ) de dicionários , onde cada dicionário representa uma **pessoa com nome e sobrenome**.
    > Um `print`  colocado entre o `return` e `def` revela o `dict` percorrido  
 2. O parametro `key` é responsavél pro percorrer cada item do dicionário e aplicar uma função sobre ele.

3. A função `ordenar` recebe cada dicionário, e retornar o valor da chave que será usado para servir **como criterio comparação** - neste caso o 'sobrenome'

4. O agoritimo interno de ordenação `sorted()` ou `list.sort()` é o resposável pro fazer a comparação e ordenar a lista em ordem alfabetica.
